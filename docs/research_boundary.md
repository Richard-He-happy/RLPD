# Research boundary

The core RLPD research algorithm and its key implementation details remain private while the associated work is unpublished. The public repository does not describe that algorithm or provide a route to reconstruct it.

The following additional research components remain private:

- research-specific initialization and candidate-selection logic
- tuned experimental parameters
- actual molecular targets
- actual peptide candidates and hits
- docking outputs
- raw research benchmark data

The public implementation uses ordinary seeded mutation, textbook UCB1, deterministic synthetic evaluation, generic DLG parsing, cache, checkpoint/resume, and single-stream CPU/GPU scheduling.
